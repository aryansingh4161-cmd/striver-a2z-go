# Linear Search

**Problem:** Return the index of the first occurrence of `target`, or −1.

`[6 7 8 4 1]`, target 4 → 3

## Approach
Check every element from left to right.
- **Time:** O(n), **Space:** O(1)

Works on **any** array. If the array is sorted, **binary search** (Step 4) does it in O(log n).
