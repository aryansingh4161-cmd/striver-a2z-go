# Step 1: Learn the Basics

**Goal:** be comfortable writing small programs in Go and thinking step by step before you touch real DSA.

| Part | Topic | What you learn |
|---|---|---|
| [1.1](1.1-go-basics/) | Go basics + time complexity | input/output, types, conditions, loops, functions, Big-O |
| [1.2](1.2-patterns/) | Patterns | nested loops (rows × columns thinking) |
| [1.3](1.3-go-collections/) | Go collections (STL equivalent) | slices, maps, sets, stacks, queues, heaps |
| [1.4](1.4-basic-maths/) | Basic maths | digits, reverse, palindrome, GCD, Armstrong, divisors, prime |
| [1.5](1.5-basic-recursion/) | Basic recursion | base case, recursion tree, stack space |
| [1.6](1.6-basic-hashing/) | Basic hashing | counting frequencies with arrays and maps |

Before 1.1, read the flowchart & pseudocode lesson in [`1.0-flowcharts-pseudocode.md`](1.0-flowcharts-pseudocode.md).
